# 产品范围

## 定位

Onegit 面向 macOS 上同时处理多个 Git 仓库和 worktree 的使用场景。它基于 Onevra 构建，目标是承接日常工作中对 Fork 的部分需求，不以覆盖 Fork 的全部功能为目标。

本文记录产品方向，已实现范围见 [README](../README.md#当前阶段)。

## 已确认方向

| 方向 | 含义 |
| --- | --- |
| 以 worktree 为主 | worktree 是日常浏览与定位工作的主要单位。 |
| 多仓库一起管理 | 在同一个应用中汇集多个仓库，查看它们的工作状态。 |
| 实时状态 | 持续呈现各 worktree 当前所在分支的状态；具体状态字段与刷新时效尚未定义。 |
| 侧边栏入口 | 侧边栏选择项目，右侧列出该项目全部 worktree，主仓库置顶；后续选择 worktree 进入对应子界面。 |

项目父目录可由用户在设置中选择并保存；启动和更换目录时扫描一次有效 Git 项目，并按目录层级展示在侧边栏。扫描遇到有效仓库即停止向内遍历；可发现所选目录内、未被上层仓库包含的 linked worktree，侧边栏不自动纳入目录外的关联 worktree；选中项目后的右侧列表会读取全部关联 worktree，不受父目录范围限制。

## 待确认的表述

“无用户操作”保留为原始要求，其具体含义尚待确认：可能指不提供 Git 写操作、无需手动刷新，或不涉及用户账号管理。当前不据此确定只读模式、自动执行 Git 操作或账号体系的范围。

## 后续再定

项目概览与 worktree 子界面是两个导航层级，当前已实现项目概览列表。worktree 子界面内容、实时状态字段及刷新机制、进一步交互与 Git 操作范围均留待后续设计。
